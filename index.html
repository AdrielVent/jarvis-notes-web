    About Jarvis Notes

    Record a voice log about your internship, meeting, or project. Jarvis transcribes it with Whisper running inside this browser, then sorts what you said into a summary, key points, and action items.

    Privacy

    • Your audio is processed on this device and is never uploaded. It is kept only until you close the tab.
    • Notes are saved in this browser's storage. There are no accounts, analytics, or API keys.
    • The first transcription downloads the Whisper model (about 40 MB) from Hugging Face, and the engine code from jsDelivr. Those two services can see your IP address, as with any download.

    Limits

    • English only, using the smallest Whisper model, so expect some wrong words. Check before you share.
    • Summaries, key points, and action items are picked from your own sentences by simple rules on this device. Nothing is invented, but nothing is checked for accuracy either.
